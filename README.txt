Nikhil Bisht - Portfolio
========================
Files:
  index.html                     - page content
  style.css                      - all styling (colours are the variables at the top)
  photo.jpg               - your profile photo (replace with another image of the same name)
  Nikhil_Bisht_Resume.pdf - resume used by the Download button (replace to update it)

How to use:
  1. Unzip the folder.
  2. Double-click index.html to open it in your browser.
  3. To publish, upload the whole folder to Netlify, GitHub Pages or Vercel.

Note: fonts (Young Serif, Figtree) load from Google Fonts, so you need to be online to see them.
