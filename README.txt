Nikhil Bisht - Portfolio
========================
Files:
  index.html  - page content (About, Experience, Projects, Skills, Contact)
  style.css   - all styling (colours are the variables at the top of the file)

How to use:
  1. Unzip the folder.
  2. Double-click index.html to open it in your browser.
  3. To publish, upload both files to Netlify, GitHub Pages or Vercel.

Note: fonts (Young Serif, Figtree) load from Google Fonts, so you need to be online to see them.
